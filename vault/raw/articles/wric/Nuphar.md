Nuphar luteum (= Nuphar polysepala)
Yellow pondlily

Yellow pondlily

Family: Nymphaeaceae (waterlily)

| Biological: grass carp | P |
| --- | --- |
| Cultural: benthic barrier | F but only if barriers are in place by early spring |
| Cultural: drawdown | P plants will recover from rhizomes |
| Cultural: shading | P can reduce size, but only with extreme shade |
| Mechanical: cutting | F but plants will regrow |
| Mechanical: hand pulling or vacuuming | G if roots and rhizomes are removed |
