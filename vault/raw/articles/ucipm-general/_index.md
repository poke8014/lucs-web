# UC IPM Pest Notes — general weed-management guidance

Source: UC Statewide Integrated Pest Management Program (UC ANR / UC Cooperative Extension).
Landing page: <https://ipm.ucanr.edu/PMG/PESTNOTES/>

Cross-cutting Pest Notes that aren't tied to a single species. These define
the **method vocabulary** the per-species pages reference — e.g. soil
solarization, mulching, hand-pulling, herbicide categories, and what
"woody weed" management generally looks like.

Useful directly for:
- Tightening the `removal_method` canonical vocabulary in
  [vault/synthesis/invasive-removal-methods.md](../../../synthesis/invasive-removal-methods.md).
- Authoring the user-facing copy in each cleanup-plan action card
  (the longer "how to actually do this" paragraph).

Scraped to markdown by [vault/scripts/scrape_ucipm.py](../../../scripts/scrape_ucipm.py).
