# Source Workspace

All application code lives here.

## Layout

```
src/
  app/
    layout.tsx          # root layout (shared <html>, fonts, metadata)
    page.tsx            # / — landing page (project index)
    globals.css
    tangtherapeutics/   # /tangtherapeutics — Tang Therapeutics massage business
      layout.tsx
      page.tsx
    sunshower/          # /sunshower — Pollinator garden project hub
      layout.tsx
      page.tsx
      Scene.tsx         # three.js scene component
      SceneBackdrop.tsx # background/sky layer for the scene
      SunshowerLanding.tsx  # landing component with yard-state prompt
      YardStateRouter.tsx   # routes user to the right phase based on yard state
      yardState.ts      # yard-state type and helpers
      care/             # /sunshower/care — Phase 4 care interstitial
        page.tsx
      site-inventory/   # /sunshower/site-inventory — site-inventory interstitial
        page.tsx
      cleanup-plan/     # /sunshower/cleanup-plan — Phase 1 MVP
        page.tsx
        PlantPicker.tsx # plant-picker UI component
        PhotoLightbox.tsx  # photo lightbox for plant photos
        photoUrl.ts     # iNaturalist photo URL helpers
        plan.ts
        resolver.ts
        types.ts
  data/
    plants.json         # DERIVED — generated by `node ops/build-plant-data.mjs` from vault
                        # plant frontmatter. Never hand-edit.
```

## Routing

Each site is a regular App Router segment under `src/app/`. Per-segment `layout.tsx` files scope fonts and metadata to that segment. There are no route groups currently.

Active routes:

- `/` — landing page
- `/tangtherapeutics` — Tang Therapeutics massage business
- `/sunshower` — Pollinator garden hub (yard-state router)
- `/sunshower/cleanup-plan` — Phase 1 weed-identification and removal planner
- `/sunshower/site-inventory` — site-inventory interstitial (bare-dirt entry point)
- `/sunshower/care` — Phase 4 care interstitial (established-yard entry point)
